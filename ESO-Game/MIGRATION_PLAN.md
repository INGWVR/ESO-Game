# План миграции на игровой движок

> Документ для будущих правок. Текущий статус: игра работает на React + DOM/CSS/SVG, миграция не требуется. Здесь зафиксированы критерии, варианты и пошаговый план на случай, если игру решат перенести на движок.

## 1. Текущее состояние

- Стек: React 19, TypeScript, Vite 6, Consta UI Kit, CSS Modules.
- Рендер: DOM / CSS / SVG (без canvas).
- Игровой цикл: `requestAnimationFrame` в `EsoGame.tsx`, физика по кадрам (интеграция Эйлера).
- Персонажи: статичный SVG-арт + CSS-анимации (наклон, сжатие, поворот лап).
- Объекты: бочки, монетки, бонусы, облака, птицы, звёзды, трава, холмы.

## 2. Критерии для миграции

Миграция оправдана при появлении хотя бы двух из:

- покадровая анимация (sprite sheets);
- уровни / тайлмапы (платформы, несколько сцен);
- сложная физика (наклоны, отскоки, динамика тел);
- большое число объектов / партиклов (DOM начинает тормозить);
- цели за пределами браузера (десктоп / мобильные сборки).

## 3. Варианты движков

| Вариант | Когда | Комментарий |
|---|---|---|
| PixiJS | нужен только быстрый 2D-рендер (WebGL) | лёгкий, работает вместе с React |
| Phaser 3 | полноценный 2D-фреймворк | спрайты, физика, сцены, TypeScript из коробки |
| Godot | бесплатный движок + экспорт в web/десктоп/мобилки | сильный 2D |
| Unity | крупный проект | избыточен для казуального раннера |

**Рекомендация:** для web-игры — Phaser 3 (или PixiJS как промежуточный шаг).

## 4. Рекомендуемый путь (Phaser 3)

1. Вынести игровую сцену в Phaser (`<canvas>`), оставив React для меню / HUD.
2. Перенести SVG-арт в спрайт-листы (растеризовать) или перерисовать.
3. Заменить rAF-цикл на `Scene.update()`.
4. Заменить CSS-анимации на Phaser tweens / sprite-анимации.
5. Коллизии — на Phaser Arcade Physics.

## 5. Соответствие компонентов

| Сейчас (React) | В Phaser |
|---|---|
| `EsoGame.tsx` (цикл, физика, спавн) | `Scene` + `update()` + спавн-логика |
| `CharacterShell.tsx` | `Sprite` + physics body + анимации |
| `characters.ts` (реестр) | конфиг + texture keys |
| `Bear.tsx` / `Rabbit.tsx` (SVG) | sprite sheets |
| `Barrel.tsx` | `Sprite` + physics body |
| `Coin.tsx` (вращение) | `Sprite` + tween (`scaleX`) |
| `Bonus.tsx` | `Sprite` |
| `Bird.tsx` / `Cloud.tsx` / `Star.tsx` | `Sprite` + параллакс |
| `GrassField.tsx` | `TileSprite` / particle |
| `GameControls.tsx` / `ScoreDisplay.tsx` | остаются на React (DOM overlay) |
| `constants.ts` / `types.ts` | переиспользуются (конфиг) |

## 6. Что переиспользовать / переписать

**Переиспользовать:** константы (размеры, физика), игровую логику (спавн, очки, рекорд), реестр персонажей, `localStorage`, UI на React.

**Переписать:** рендер (DOM → canvas/WebGL), цикл (rAF → `update`), коллизии (ручные → Arcade Physics), анимации (CSS → tweens/sprite).

## 7. Порядок работ (если решимся)

1. Proof-of-concept: Phaser-сцена с одним спрайтом и прыжком.
2. Перенести персонажа (спрайт-лист, анимации, физика прыжка).
3. Перенести объекты (бочки, монетки, бонусы) и коллизии.
4. Перенести фон (параллакс: холмы, облака, птицы, трава).
5. Подключить React-оверлей (меню, HUD, звук).
6. Удалить старый рендер и прогнать проверки.
