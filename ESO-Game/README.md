# Игра «Косолапый забег»

Браузерная игра-раннер: персонаж бежит по дороге, собирает монетки и перепрыгивает бочки. Есть выбор персонажа, дневной/ночной режим и звук.

## Возможности

- 🐻 **Выбор персонажа** — Мишка и Кролик; новых персонажей легко добавить.
- 🪙 **Монетки** — объёмные, с вращением вокруг оси (при повороте видно ребро).
- 🛢️ **Бочки** — препятствия, которые нужно перепрыгивать.
- ⭐ **Бонусы** — редкие предметы, дающие больше очков.
- 🦘 **Физика прыжка** — переменная высота (короткое нажатие — низкий прыжок, удержание — высокий) и «зависание» у вершины.
- 🌙 **Дневной/ночной режим** — переключатель темы.
- 🐦 **Живой фон** — параллакс, холмы и горы, облака, птицы, трава.
- 🔊 **Звук** — эффекты прыжка/монетки/бонуса и кнопка отключения звука.
- 💾 **Сохранение** — рекорд, выбранный персонаж и настройка звука в `localStorage`.
- 📱 **Адаптивность** — мобильные медиа-запросы.

## Технологии

- [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Vite 6](https://vite.dev/)
- [Consta UI Kit](https://consta.design/) (`@consta/uikit`, `@consta/icons`)
- CSS Modules
- Игровой цикл на `requestAnimationFrame`, физика на кадрах

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
```

Остальные команды:

```bash
npm run build     # сборка (tsc -b && vite build)
npm run lint      # eslint
npm run preview   # предпросмотр собранной версии
```

> Работают также `pnpm` и `yarn` (в репозитории есть `package-lock.json` и `yarn.lock`).

## Управление

- **Пробел** или **стрелка вверх** — прыжок (короткое нажатие — низкий, удержание — высокий).
- **Клик/тап** по персонажу — тоже прыжок (и старт игры).

## Как добавить нового персонажа

1. Создайте компонент с SVG-артом персонажа (пример — `Bear.tsx` или `Rabbit.tsx`).
2. Добавьте запись в реестр `characters.ts` со полями:
   `id`, `label`, `emoji`, `Art`, `bottomOffset`, `shadowWidth`, `shadowLeftOffset`.
3. Добавьте новый `id` в тип `CharacterType` в `types.ts`.

Селектор персонажа, рендер, тень и анимации лап подхватятся автоматически.

## Структура проекта

```
src/
├── App.tsx                  # корневой компонент, тема (день/ночь)
├── main.tsx                 # точка входа
└── components/
    ├── EsoGame.tsx          # игровой цикл, физика, отрисовка
    ├── CharacterShell.tsx   # общая обёртка персонажа (контейнер, хитбокс, анимации)
    ├── characters.ts        # реестр персонажей
    ├── Bear.tsx             # арт медведя
    ├── Rabbit.tsx           # арт кролика
    ├── Barrel.tsx           # бочка
    ├── Coin.tsx             # монетка (вращение с ребром)
    ├── Bonus.tsx            # бонус
    ├── Bird.tsx             # птицы
    ├── Cloud.tsx            # облака
    ├── Star.tsx             # звёзды (ночной режим)
    ├── GrassField.tsx       # трава (параллакс)
    ├── GameControls.tsx     # стартовый/финальный экраны, выбор персонажа
    ├── ScoreDisplay.tsx     # HUD (монетки / очки / рекорд)
    ├── constants.ts         # игровые константы
    ├── types.ts             # типы
    ├── index.ts             # публичные экспорты
    └── EsoGame.module.css   # стили
public/
└── sounds/                  # jump.mp3, coin.mp3, bonus.mp3
```

## Механика вкратце

- **Очки** растут со временем в игре; **монетки** дают +5, **бонусы** — +20.
- **Скорость** игры плавно растёт с ростом счёта (до максимума).
- **Рекорд** сохраняется между сессиями.
